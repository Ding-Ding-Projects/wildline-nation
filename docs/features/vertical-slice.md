# Harbourlight vertical slice

Version 0.1.0 was intentionally narrow and playable: one city, one Rest Stop, representative shops, one creature, one battle contract, one minigame, one bus loop, one subway line, and one visible template-house build. It established the central rule that the game is about visiting places and living in a city; battles are a paid activity rather than the geography key.

Version 0.2.0 retains that foundation while expanding it to three complete cities, physical ferry and airport buildings, route-specific tickets, resumable intercity journeys, and a five-stop streetcar loop in every city. See [Three-city transport network](transit-and-rest-stops.md) for the current contract.
