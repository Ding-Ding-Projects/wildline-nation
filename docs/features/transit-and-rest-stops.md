# Transit and Rest Stops

Harbourlight contains a rideable Blue Subway Loop and Route 7 Bayfront Bus Loop. Boarding is a physical transit action; the player receives a starting national basic pass so exploration is open from the first moment. The slice reports the route and next stop, with the full Yum Tong network adding actual vehicle motion, route geometry, station interiors, schedules, capacity, transfers, and disruptions.

The Rest Stop provides a basement for local tools and help, a ground floor for creature care, battle licensing, transit information, and a universal washroom, and a second floor for physical shops. Its plaza is the civic anchor outside.
