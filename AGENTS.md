# Contributor instructions

This file is the public, sanitized project mirror of the shared contributor instructions. Keep private credentials, machine paths, host details, and private conversational vocabulary out of this file and all public records.

## Build boundary

- Use `build.bat` for the runnable desktop build and `build-installer.bat` for the unsigned Squirrel.Windows installer.
- Do not add code signing, credentials, telemetry, analytics, or cloud-save requirements.
- Keep the Day Teet Hui non-playable and use original project assets.
- Every shop or service purchase must require an in-world physical-place context; informational GUI surfaces must not complete transactions.
- Construction contracts and worker hiring must require an in-person builder-office context.

## Documentation

Update the README, categorized feature docs, roadmap, and handoff when behavior changes. Public records use ordinary technical language and must never contain private credentials or machine-specific details.
